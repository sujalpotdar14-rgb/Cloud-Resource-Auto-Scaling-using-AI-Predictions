AWS Lambda Handler (lambda_function.py) Python 3.12 
import json, boto3
comprehend = boto3.client('comprehend', region_name='us-east-1')
dynamodb = boto3.resource('dynamodb').Table('SentimentLogs')

def lambda_handler(event, context):
    body = json.loads(event.get('body', '{}'))
    text = body.get('text', '')
    
    # Call Amazon Comprehend Sentiment API
    res = comprehend.detect_sentiment(
        Text=text, LanguageCode='en'
    )
    
    # Async persistence into DynamoDB
    dynamodb.put_item(Item={
        'id': context.aws_request_id,
        'sentiment': res['Sentiment'],
        'scores': res['SentimentScore']
    })
    
    return {
        'statusCode': 200,
        'headers': {'Access-Control-Allow-Origin': '*'},
        'body': json.dumps(res)
    }

                 Infrastructure as Code
                
Production Deployment Source Code

                
Deploy this exact microservice directly to your AWS Account using AWS SAM, Terraform, Docker, or AWS CLI scripts.

            


            

                

                    
                    
                    
                    
                    
                


                

                    

                        template.yaml
                        
                    

                    
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31
Description: Sentiment Analysis Microservice on AWS Serverless

Resources:
  SentimentApi:
    Type: AWS::Serverless::Api
    Properties:
      StageName: prod
      Cors:
        AllowMethods: "'POST,GET,OPTIONS'"
        AllowHeaders: "'Content-Type,X-Amz-Date,Authorization,X-Api-Key'"
        AllowOrigin: "'*'"

  SentimentFunction:
    Type: AWS::Serverless::Function
    Properties:
      CodeUri: ./backend
      Handler: lambda_function.lambda_handler
      Runtime: python3.12
      Architectures: [arm64]
      Timeout: 10
      MemorySize: 512
      Policies:
        - ComprehendBasicAccessPolicy: {}
        - DynamoDBCrudPolicy:
            TableName: !Ref SentimentLogsTable
      Events:
        AnalyzeApi:
          Type: Api
          Properties:
            RestApiId: !Ref SentimentApi
            Path: /api/v1/analyze
            Method: POST

  SentimentLogsTable:
    Type: AWS::DynamoDB::Table
    Properties:
      TableName: SentimentLogs
      AttributeDefinitions:
        - AttributeName: id
          AttributeType: S
      KeySchema:
        - AttributeName: id
          KeyType: HASH
      BillingMode: PAY_PER_REQUEST
