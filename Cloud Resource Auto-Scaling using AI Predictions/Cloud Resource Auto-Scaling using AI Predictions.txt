1. EXECUTIVE SUMMARY
--------------------
Cloud infrastructure auto-scaling traditionally relies on reactive policies (e.g., triggering scale-out only after CPU utilization exceeds 70% for 5 consecutive minutes). In modern web applications, reactive scaling causes severe service latency degradation and HTTP 503 errors because provisioning new cloud server instances takes several minutes (cold-start latency).

This project implements a Proactive Cloud Resource Auto-Scaling System using Artificial Intelligence & Machine Learning Time-Series Forecasting. By training an ensemble ML model (RandomForest + Ridge Regression with temporal and rolling lag features), the system forecasts workload CPU demand and traffic spikes 15 to 30 minutes into the future. 

When an imminent traffic surge is detected, the AI engine pre-warms cloud capacity ahead of time, ensuring that extra EC2 instances are fully operational before the surge arrives—all while maintaining a strict ₹0.00 (Zero-Cost) policy for AWS usage.

3. CORE COMPONENT ARCHITECTURE
-------------------------------
- `ai_engine.py`: Machine Learning time-series prediction model (`WorkloadPredictor`) and proactive auto-scaler policy evaluator (`AutoScalerPolicy`).
- `aws_controller.py`: AWS Boto3 integration client, AWS Zero-Cost Guard, and Local AWS EC2/ASG Simulator.
- `server.py`: FastAPI REST API server handling real-time telemetry streaming, workload pattern simulation, and scaling strategy toggles.
- `static/index.html`, `static/style.css`, `static/app.js`: Interactive futuristic glassmorphic Web Dashboard featuring Chart.js real-time graphing, active instance fleet node visualizer, traffic spike generator, and live event audit feed.
- `run_app.py`: One-click startup script launching the Python backend server at http://localhost:8000 and opening the default browser.
